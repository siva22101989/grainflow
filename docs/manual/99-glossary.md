# Glossary

Terms used throughout the GrainFlow application and this manual.

## Storage & Inventory

| Term | Definition |
|------|-----------|
| **Inflow** | Stock coming into the warehouse. Each inflow creates a storage record. |
| **Outflow** | Stock leaving the warehouse. Can be single-record or bulk. |
| **Bags** | The standard unit of measure for commodities. One bag is one physical sack of grain/commodity. |
| **Storage Record** | A single entry tracking one batch of commodity for one customer, from inflow to outflow. |
| **Lot** | A physical zone or area within the warehouse (e.g., Row A, Section B, Shed 3). |
| **Commodity** | The type of grain or product stored (e.g., Paddy, Wheat, Red Gram, Cotton). |
| **FIFO** | First-In, First-Out. The allocation strategy used for bulk outflow, where the oldest stock is withdrawn first. |
| **Bulk Outflow** | Withdrawing bags across multiple storage records in a single operation. |

## Financial

| Term | Definition |
|------|-----------|
| **Hamali** | Labor charges for loading and unloading bags at the warehouse. Charged per bag. |
| **Rent** | Storage fee charged based on duration and number of bags. Tiered pricing: Rs. 36/bag for 0-6 months, Rs. 55/bag for 7-12 months. |
| **Khata** | An initial advance or credit amount recorded at the time of inflow. |
| **Total Due** | The sum of all unpaid rent and hamali charges for a customer. |
| **Payment Allocation** | Distributing a single payment across multiple storage records, typically using FIFO. |
| **Discount** | A reduction applied to the calculated rent during outflow. |

## Users & Roles

| Term | Definition |
|------|-----------|
| **Super Admin** | System-wide administrator with access to all warehouses and the admin panel. |
| **Owner** | The warehouse owner with full access to their warehouse operations and settings. |
| **Admin** | A warehouse administrator with full operational access but no system-level admin. |
| **Manager** | A warehouse manager with read access to reports and analytics but limited write access. |
| **Staff** | A warehouse worker with basic inflow, outflow, and payment recording capabilities. |
| **Customer** | An end customer who stores goods. Has read-only portal access to view their own records. |

## Subscription & Billing

| Term | Definition |
|------|-----------|
| **Plan Tier** | The subscription level: Free, Starter, Professional, or Enterprise. |
| **Grace Period** | A 7-day window after subscription expiry before downgrade to Free tier. |
| **Activation Code** | A code generated by super admins that customers can redeem to activate a plan. |
| **Payment Link** | A Razorpay-generated URL sent to customers for online payment. |

## Technical

| Term | Definition |
|------|-----------|
| **RLS** | Row Level Security. A database feature that ensures users can only see data from their assigned warehouses. |
| **Warehouse Isolation** | The principle that data from one warehouse is never visible to users of another warehouse. |
| **Soft Delete** | Marking a record as deleted without physically removing it from the database. Allows recovery. |
| **Audit Trail** | An automatic log of all changes made in the system, including who changed what and when. |
| **Webhook** | An automated notification from Razorpay to GrainFlow when a payment status changes. |
